# Осколки Неба

Тактическая арена 3 на 3 на обломках небесного храма. Разбей Оболочку, подбери
осколок и донеси его на базу — носитель осколка замедлен вдвое, а враг уже бежит
с другого фланга.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D / стрелки | движение (относительно камеры) |
| 1 | способность 1 (рывок / исцеление / залп) |
| 2 | способность 2 (оглушение / лозы / оглушающая стрела) |
| 3 | ультимативная способность |
| R | новый бой после победы или поражения |

Атака автоматическая: герой бьёт ближайшую цель в радиусе. Способности можно
нажимать и мышью по панели справа снизу.

## Правила матча

- выбор класса в начале: Воин, Маг, Фея; остальные слоты занимают боты;
- Оболочка пробуждается у алтаря, предупреждение 10 секунд, окно на убийство 45 секунд;
- после гибели Оболочки падает осколок: подбери его и донеси в круг своей базы;
- первый, кто принёс три осколка, побеждает; матч длится 5 минут;
- при равном счёте по таймеру следующий осколок решает исход;
- время возрождения 8 секунд.

## Структура проекта

```
scenes/Main.tscn        главная сцена: арена, камера
scripts/game.gd         матч, Оболочка, осколок, VFX
scripts/hero.gd         герой, классы, способности, боты
scripts/shell.gd        Оболочка и молнии
scripts/hud.gd          интерфейс
scripts/arena_kit.gd    генерация арены (остров, руины, свет)
assets/concept/         референсы с борда
art/generated/          модели героев и Оболочки
art/textures/           текстуры камня
audio/                  музыка и звуки боя
```

Запуск: F5 в Godot (Summer Engine) — стартовая сцена `res://scenes/Main.tscn`.
