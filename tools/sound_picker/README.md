# Sound Picker — подбор звуков для «Небесных осколков»

Отдельный инструмент продюсера: выбрать папку со звуками, прослушать файлы, разложить их по слотам игры и выгрузить JSON для агента.

Инструмент **не изменяет игру**: не трогает сцены, скрипты, существующие звуки и не копирует файлы. Он только читает выбранную папку и хранит назначения в `localStorage` браузера.

## Требования

- Windows.
- Python 3 (проверено на 3.10 и 3.14) — используется только стандартный `http.server`, без пакетов.
- Браузер Chrome, Edge, Яндекс.Браузер или другой Chromium (нужен File System Access API).
- Порт по умолчанию — **8090**, чтобы не пересекаться с локальным сервером игры на 8080.

## Запуск

### Вариант 1 — ярлык (рекомендуется)

1. Дважды кликните `start.bat`.
2. Откроется окно сервера и браузер: **http://localhost:8090/**
3. Чтобы остановить сервер, закройте окно «Sound Picker Server».

### Вариант 2 — вручную

```bat
cd C:\myGames3D\three-skies\tools\sound_picker
python -m http.server 8090
```

Затем откройте в браузере: **http://localhost:8090/**

### Другой порт

```bat
start.bat 8081
```

или вручную:

```bat
python -m http.server 8081
```

и откройте **http://localhost:8081/**. Если порт занят, выберите любой свободный (например, 8091).

> Важно: открывать `index.html` через `file://` нельзя. В этом режиме браузер блокирует выбор папки и чтение файлов — нужен именно HTTP-сервер.

## Как пользоваться

1. Нажмите **«Выбрать папку со звуками»** и укажите папку, например:
   `C:\myGames3D\three-skies\assets\audio`.
   Инструмент рекурсивно читает вложенные папки и показывает все файлы `.ogg`, `.wav`, `.mp3`, `.flac`, `.m4a`, `.aac`, `.opus`, `.webm`, `.aiff`.
2. Слева выберите звук: **▶** — прослушать, **«Назначить»** — сделать звук выбранным.
3. Кликните по нужному слоту справа — звук назначится. Один и тот же звук можно назначить в несколько слотов; новое назначение заменяет старое.
4. В заполненном слоте есть **▶** (проверить, что лежит) и **«Очистить»**.
5. **«Сохранить»** (или `Ctrl+S`) — сохранить назначения в браузере. После перезагрузки вкладки они восстановятся.
6. **«Скопировать JSON»** — скопировать итоговую структуру в буфер обмена.
7. Если добавили звуки в папку — нажмите **«Выбрать папку»** снова (или **«Перечитать»**, если браузер даёт доступ к той же папке). Новые файлы появятся в списке.

После перезагрузки страницы назначения видны сразу, но для прослушивания нужно снова выбрать папку — браузер не хранит доступ к файлам между сессиями.

## Слоты способностей

В игре у каждого класса **три** кнопки способностей, поэтому в инструменте тоже три слота: `skill1`, `skill2`, `ult`. Третий слот — это ульта (у Феи — «Золотое благословение», её третья способность).

| Класс | `skill1` | `skill2` | `ult` |
|---|---|---|---|
| Воин | Теневой рывок | Жажда крови | Крик ужаса (ульта) |
| Фея | Оглушающий выстрел | 100% Крит | Золотое благословение (ульта) |
| Маг | Лозы | Исцеление | Грозовой шквал (ульта) |

Отдельного `skill3` нет: четвёртой способности в игре не существует. Если в старом сохранении остался `skill3`, инструмент его игнорирует.

## Формат JSON

Пустые слоты выводятся как `null`:

```json
{
  "warrior": {
    "attack": "attack_sword.ogg",
    "skill1": null,
    "skill2": null,
    "ult": null,
    "hit": null,
    "death": null
  },
  "fairy": {
    "attack": null,
    "skill1": null,
    "skill2": null,
    "ult": null,
    "hit": null,
    "death": null
  },
  "mage": {
    "attack": null,
    "skill1": null,
    "skill2": null,
    "ult": null,
    "hit": null,
    "death": null
  },
  "misc": {
    "shard_delivered": null,
    "shard_picked": null,
    "coin_pickup": null,
    "shell_hit": null,
    "shell_destroyed": null,
    "victory": null,
    "defeat": null,
    "match_start": null
  }
}
```

В JSON попадает **имя файла** (например, `hit_01.ogg`). Во внутреннем сохранении также хранится относительный путь, чтобы различать одноимённые файлы из разных подпапок.

## Где хранятся назначения

`localStorage` браузера, ключ:

```
sky-shards.sound-picker.v1
```

Это только локальное состояние инструмента. Чтобы перенести назначения в проект, используйте **«Скопировать JSON»** и передайте результат агенту.

## Ограничения

- **Chrome/Edge**: используется File System Access API (`showDirectoryPicker`) — полноценный выбор папки.
- **Firefox/Safari**: сработает запасной вариант `input[type=file][webkitdirectory]`; папка читается, но после перезагрузки её нужно выбирать заново.
- **Старые браузеры** без поддержки выбора папки увидят понятное предупреждение.
- Аудио играет через стандартный HTML5 `Audio`; файлы не копируются и не изменяются.
- Закрытие вкладки с несохранёнными назначениями вызовет предупреждение браузера.
