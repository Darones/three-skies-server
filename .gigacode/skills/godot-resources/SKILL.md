# Навык: Проверка ресурсов
Перед тем как предложить код с загрузкой ресурсов (load, preload):
1. Проверь, существует ли файл по указанному пути `res://`.
2. Если путь ведет к папке, убедись, что там есть нужный `.glb` или `.png`.
3. Если ты не уверен в пути, сначала посмотри список файлов в директории, и только потом пиши код.
