# Навык: Редактирование UI и сцен (.tscn)
1. ЗАПРЕЩЕНО использовать скрипты или MCP для создания кнопок. 
2. Открывай файлы `.tscn` как обычный текст через файловую систему.
3. Вручную прописывай узлы (Control, TextureRect, Button), якоря (anchors_preset) и пути к текстурам.
4. Для картинок используй `expand_mode = EXPAND_FIT_WIDTH_PROPORTIONAL` и `stretch_mode = STRETCH_KEEP_ASPECT_CENTERED`.
