## Риски и заметки

- Web = Compatibility: картинка светлее и площе; тёмную тему лобби не менять.
- Self-signed HTTPS даёт предупреждение; Tailscale Serve — чистый вариант без предупреждений.
- Не менять экономику, ботов, цены и рекламу.
- A56: 1080×2340, 19.5:9, CSS ~915×412, DPR 2.625; проверять 20:9.
- Если `content_scale_size` ломает safe area — считать инсеты в базовых координатах.
