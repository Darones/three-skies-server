## Что уже работает

- VK-авторизация через HMAC launch params; серверный профиль `platform='vk'`.
- OK-авторизация: единый build определяет OK по `vk_client=ok`/referrer
  `ok.ru` и включает `OKAdapter`. Вход через `VKWebAppGetUserInfo(use_local:true)` →
  `/auth/ok` (`ok_user_id`, имя). OK отдаёт результат в обёртке
  `{type, data}` — клиент разворачивает; fallback — `vk_ok_user_id` из URL.
  `OK_APP_KEY` для входа не нужен. Прогресс VK и OK раздельный.
- Реклама VK: rewarded x2 работает на ПК; на iPhone VK не даёт reward-fill
  (внешний фактор, не подделывать награду); интерстишиал после итогов;
  серверный x2 один раз за бой.
- Юридика минимальная: на стартовом загрузчике «12+» сверху справа и
  строка «Продолжая игру, вы подтверждаете, что вам уже есть 12 лет,
  и соглашаетесь с политикой конфиденциальности»; после старта они
  скрываются. «Удалить данные» ниже «Сбросить общий прогресс» в настройках.
  Отдельных юридических экранов и KayKit credits нет (KayKit — CC0).
- Сервер: `/auth/ok`, `/account/delete` (профиль удаляется, статистика
  обезличивается), серверные XP/награды, статистика.

## Правила работы

- Сначала доказательство: лог, скриншот, таймстемп, размер файла. Потом правка.
- Не менять геймплей, баланс, ботов и экономику без прямой просьбы.
- Деплой только при `/health.live_matches == 0`; после деплоя проверять
  `/health`, `Content-Length /game*/index.pck` и `fileSizes`, а не только пуш.

  «Сбросить зависшую сборку», затем «Редеплой».
- Исходники: ветка `mobile-ui` содержит незакоммиченные изменения
  (ads/OK/loading/settings); в `main` — собранные `server/web*`.
  Перед правками сверять `git status` в обоих местах.
