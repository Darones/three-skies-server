# Возможные причины отказа модерации — «Небесные осколки»

Дата: 24.11.2026.
Источники: Правила VK Mini Apps (редакция 13.11.2026), гайд OK
(dev.vk.com/ru/ok), отказы других игр пользователя, `docs/VK-COMPLIANCE.md`,
`docs/PLATFORM-ADAPTERS.md`, `docs/DIFFICULTY-PLAN.md`.

Статусы:

- ✅ закрыто;
- 🟡 проверить / частично;
- 🟠 в работе;
- ❌ дыра / блокер;
- ⚠️ риск.

Важно: это **возможные** причины, а не гарантия отказа. Модератор может
зацепиться за любую из них.

---

## 0. Главное

Сейчас M2 (VK-авторизация) выкачен и реальный вход через VK работает.
Но для каталога игр всё ещё не закрыты:

1. **4.2.4** — первый экран и обучение: слишком много функций, механик и текста.
2. **4.2.1** — нет реальной монетизации (VK Голоса/реклама).
3. **M3** — 12+, согласие, удаление данных, UGC-правила и 48 часов, поддержка.
4. **UI/визуал** — обрезанная рамка, серый текст, разный стиль, «AI-generated».
5. **OK** — полностью отдельная сборка и модерация (ОКи, OK-ссылки, прогресс).

Пока эти пункты не закрыты, подача в каталог игр VK, скорее всего, снова
получит отказ.

## 15. Как закрыть/пройти каждую причину (честно, без обмана модератора)

«Обойти» здесь = **упростить продукт и убрать лишнее**, а не спрятать
нарушение. Обман (фейковая оплата, фейковая реклама, поддельный sign,
боты за людей, скрытые ссылки) рано или поздно даёт отказ или бан.

### 15.1 Авторизация и прогресс

- **1.2.2 / 4.2.3.** Уже сделано в M2: VK launch params, HMAC + legacy MD5,
  профиль по `vk_user_id`, без отдельной регистрации. Держать unit-тесты
  на sign и реальный вход из VK. Не логировать секрет.
- **2.3.8.** Всё, что игрок «нажил», хранить на сервере: XP, уровни,
  обучение, `matches_played/novice`, осколки, скины, оружие, статистику.
  Локальный `user://` — только кэш. Проверка: два устройства → один профиль.
- **1.1.10.** Кнопка «Удалить аккаунт» в настройках, ниже «Очистить данные»:
  подтверждение, серверное удаление/анонимизация, разлогин, платёжные
  записи — по закону, без лишнего.
- **1.2.5.** Секреты только в env RelaxDev; в PCK/HTML/клиенте их нет.
- **1.2.6.** Rate-limit на `/auth/vk`, `/profile`, `/progress`, WS; реальный
  IP из `X-Forwarded-For`; не блокировать всех одним прокси.
- **1.2.7.** Валидировать вход, не отдавать пути/стектрейсы, корректные JSON.

### 15.2 Юридика, возраст, UGC, поддержка

- **1.1.4.** Взять **типовые документы ВК** (соглашение + политика) в Панели
  управления. Если ВК не показывает их при запуске — одна строка на загрузке:
  «Продолжая, вы принимаете…» + ссылки. Не делать отдельный большой экран.
- **2.1.5.** Плашка **12+** на загрузке/первом экране + рейтинг 12+ в Панели.
  Экран возраста и согласие не нужны.
- **1.1.10.** Удаление аккаунта — см. 15.1.
- **2.4.1 / 2.4.2.** Поддержка в футере/сообществе; ответ ≤7 дней. Данные
  разработчика — в описании/соглашении/сообществе. Не добавлять лишнюю
  кнопку на велком; футер и настройки достаточно.
- **2.5.1.** Ники — только из VK, смена запрещена. Короткий раздел UGC в
  «Правилах» + принятие. Серверный санитайз VK-имени, fallback «Игрок».
- **2.5.2.** Кнопка «Пожаловаться» + **ручная** очередь жалоб (не только
  автофильтр). Жалоба хранит: кто, на кого, ник, матч, время, причина.
- **2.5.3.** SLA **48 часов**: переименовать/скрыть/забанить, лог, ответ.
  Админ-инструмент или простая таблица жалоб.
- **2.1.3.** Честно раскрыть ботов в правилах/загрузке («в первых матчах
  могут быть боты»); не выдавать ботов за живых с фейковым чатом.
- **2.1.4.** Экран «Кредиты»: KayKit, BinbunVFX, музыка, SFX, AI-ассеты,
  лицензии. Добавить до подачи.
- **4.1.8 / 4.2.3.** Никаких RelaxDev/GitHub/сайтов в игре; поддержка —
  VK-сообщество/контакт. В OK — только OK-ссылки.
- **3.1.1–3.1.3.** Все тексты на русском, без опечаток; проверить карточки,
  магазин, обучение, ошибки.

### 15.3 Первый экран, обучение, сложность, UI

- **4.2.4. Первый экран:**
  - логотип «Небесные осколки»;
  - одна кнопка **«Играть»**;
  - мелкая «Правила»;
  - плашка 12+ и юр. строка;
  - маленькие иконки настроек/профиля.
  Убрать: классы, магазин, XP, баланс, вторую кнопку «Обучение», сообщество,
  поддержку. Всё это — после обучения или под «Ещё».
- **4.2.4. Класс:** в обучении — Воин по умолчанию. Выбор класса — после
  обучения, отдельным экраном с тремя карточками и одной строкой описания.
- **4.2.4. Обучение:** движение → атака → способность 1 → способность 2 →
  монеты → лавка → 2v2 → 3v3 без Оболочки → Оболочка. Одна механика за шаг.
  Кнопки способностей 2/3 скрыты, пока не наступил их этап.
- **4.2.4. Текст:** одна карточка = 1–2 предложения. Подробности — в
  «Правилах». Убрать тур по UI и абзацы про экономику.
- **4.1.6.4. Сложность:** новичковый пул, лёгкие боты, первые 1–3 матча
  winnable; не ставить новичка к ветеранам; тестировать 1–3 матча после
  обучения. Боты не «мебель», но и не убивают.
- **4.2.10. Стартовое меню:** после упрощения первого экрана все опции
  должны быть доступны: игра, обучение, правила, настройки, магазин,
  инвентарь, выход в лобби из боя.
- **3.3.2 / 3.4.1.** Один шрифт, один стиль кнопок, одинаковые иконки;
  кнопки не в несколько строк, с нормальными отступами; контрастный текст
  на тёмной плашке; никакого серого на сером.
- **3.2.1 / 3.2.2.** Проверить 1440×734, 390×844, 360×640; safe area;
  ничего не обрезается; инвентарь/магазин не вылезают вправо; карточки
  не ломают сетку.
- **4.2.5 / 4.1.6.1.** Единая арт-дирекция: палитра, свет, шрифт, иконки,
  карточки. Не смешивать яркие AI-карточки с серой low-poly ареной.
  Уникальный крючок — 3v3 + Оболочка + осколок; усилить его ключевым
  артом и парой фирменных анимаций/VFX.
- **4.2.12.** XP/уровни — за матч (активное действие). Если x2 за рекламу
  удваивает XP — это риск; безопаснее x2 только на осколки, а XP не удваивать.

### 15.4 Монетизация, реклама, платежи

- **4.2.1. Быстрый путь:** для первой подачи достаточно **VK Ads** —
  rewarded + interstitial. VK Голоса/платежи можно добавить позже.
  Это закрывает «монетизация есть» без кассы и налогов.
- **Rewarded (x2):** кнопка «x2 осколки за рекламу» на результатах; награда
  только после `rewarded`; отмена/ошибка — без награды; один раз за бой;
  серверное начисление; дневной кап.
- **Interstitial:** после боя, когда игрок уже посмотрел итоги и нажал
  «В лобби»; не перед боем, не в матчмейкинге, не в обучении, не на
  первом запуске. Новичок — не чаще 1/30 мин; не новичок — каждый выход
  в лобби. Кнопка/лейбл «Реклама» предупреждает.
- **5.1.2.** Только VK Ads, без сторонних сетей.
- **5.1.5.2(e).** Осколки должны зарабатываться в бою; реклама — бонус,
  не единственный путь.
- **VK Голоса:** виртуальные ценности только за Голоса; без вывода,
  обмена, передачи между игроками; без оплаты деньгами за виртуальное.
- **Платежи:** `get_item`/`order_status_change`, `status=chargeable`,
  валидный JSON, непустой `photo_url`, `_test`/боевой, тестировщики,
  кабинет выплат; начисление на сервере, не на клиенте.
- **Фейки:** никаких mock-таймеров, «оплата» без платежа, «реклама» без
  адаптера. Заглушка «скоро» — можно, но она не должна начислять.
- **OK:** ОКи, OK-платежи, `?app=`, fallback, отдельная экономика.

### 15.5 OK-сборка

- Отдельный билд `web-ok`, `VK Bridge`, `vk_client=ok`, `local_access_token`,
  `use_local`.
- Цены в **ОКах**, тексты «За ОКи», никаких «голосов».
- Шеринг только `ok.ru/app/<OK_APP_ID>`; сторис — OK.
- Никаких VK/GitHub/RelaxDev/внешних ссылок.
- Прогресс OK отдельно: `platform='ok'`, свои ключи облака/локального сейва.
- OK-платежи: `get_item` на `/vk/pay` с `site=OK`; `callbacks.payment` на
  `/ok/pay`; без `status`; fallback `{"status":"ok"}`; OK App ID в карте
  магазинов; `photo_url` на своём CDN.
- VK-методы, которых нет в OK (`AddToHomeScreen`, `AddToFavorites`), не
  вызывать; проверять `Unsupported platform`.
- OK-модерация — после VK; не подавать обе площадки одновременно.

### 15.6 Техника и стабильность

- VK Bridge инициализирован; `VKWebAppViewHide` глушит звук; звук после
  первого тапа; настройка звука.
- Загрузка: прогресс/спиннер, нет бесконечного экрана; PCK 49 МБ — сжать
  ассеты, если долго; проверить на телефоне и в VK iframe.
- iPhone/VK webview: вход, лобби, обучение, бой; редирект `/game-vk/?v=...`
  не теряет `vk_user_id/sign/vk_ts`.
- Android/desktop: те же сценарии; safe area; джойстик/кнопки; ник на телефоне.
- Сеть: реконнект WS, таймауты, понятные ошибки; rate-limit; HTTPS.
- Логи: без секретов/подписей/полных launch params.

### 15.7 Оформление, store art, кредиты

- Иконка/баннер/скриншоты без VK-логотипов, бейджей, цифр, рамок.
- Название без «VK/ВК/ВКонтакте»; 12+ на карточке.
- Скриншоты: первый экран, обучение, бой, Оболочка, магазин; без обрезки.
- Кредиты: KayKit, BinbunVFX, музыка, SFX, AI; лицензии.
- Описание: что за игра, управление, 12+, без внешних ссылок.

### 15.8 Процесс

- Не подавать, пока P0 не закрыты; не спамить повторными заявками.
- Перед подачей: `/health.live_matches == 0`, бэкап, тест 2 аккаунта,

- занижение возраста/18+ контент под 12+;
- UGC без правил, жалоб и 48 часов;
