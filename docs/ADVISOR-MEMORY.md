## 3. Решения по игре

### 3.1. Регистрация и прогресс

- Отдельной регистрации нет: вход через VK, identity — `vk_user_id`.
- Ник — имя из VK; смена в игре запрещена (проще для UGC/модерации).
- Прогресс серверный: XP, уровни, обучение, осколки, скины, оружие,
  `matches_played/novice`. `user://` — только кэш.
- Один VK-аккаунт на двух устройствах — один профиль.
- Второй VK-аккаунт — отдельный профиль.
- Старые standalone-профили не мигрируют в VK автоматически.
- 103 старых профиля — тесты; реальных старых игроков нет.
- Другу/тесту нельзя начислить до первого входа: VK-вход создаст профиль,
  иначе начисление уйдёт на пустышку.

### 3.2. Обучение: бой

- Игрок — Воин; 10 урона за удар, HP не ниже 1, смерть запрещена.
- Союзный бот получает 10 урона, HP не ниже 1, не умирает;
  сам бьёт обычным уроном.
- 1v1: игрок Воин против Охотницы (FAIRY). Охотница стоит на месте,
  стреляет 10, не бежит на базу, не отступает, не лечится.
- 2v2: игрок Воин + союзник Охотница против Мага + Охотницы.
- 3v3: игрок Воин + Маг + Охотница против Воина + Мага + Охотницы.
- 2v2/3v3: максимум 60 секунд; таймаут = победа и переход дальше.
- Боты спавнятся один раз на этап; после смерти **не респавнятся**.
- 2v2/3v3: боты не стоят и не дерутся со своей базы; максимум 1–2 с
  спавна, затем все выходят; атаки из базы запрещены.
- Оболочка: после «Оболочка пробуждается» — 2 секунды, затем спавн;
  HP 1000, после 25 с — 700; пассивна.
- В обучении нет поражения; таймаут = победа.

### 3.3. Обучение: UI

- Главная плашка с текстом — сверху по центру; края не перекрывают
  аватарку и «Пропустить обучение».
- Фонтан: маленькая подсказка **слева под аватаркой**, «Собери 15 монет»;
  без кнопки закрытия; появляется при подходе, исчезает при уходе.
- Магазин: маленькая подсказка **там же, слева под аватаркой**,
  «Купи „Крылатые ботинки“: +15% скорости»; без кнопки закрытия;
  появляется при подходе, исчезает при уходе.
- Старый оверлей «Выбери героя света» на старте боя убрать; в обучении Воин.
- В будущем — упрощённая версия для новичков: только «Играть», Воин,
  без выбора класса. Пока не делать.

### 3.4. Загрузка, 12+, юридика

- «12+» — на начальном экране загрузки, белым жирным текстом, без рамки.
- Убрать 12+ из экрана поиска матча.
- Под полоской прогресса — белым с чёрной обводкой:
  «Продолжая игру, вы подтверждаете, что вам уже есть 12 лет,
  и соглашаетесь с политикой конфиденциальности.»
- Ссылка — только на типовую политику VK/страницу приложения.
- Удаление аккаунта, UGC-правила, 48 часов, поддержка — M3.

### 3.5. Реклама и платежи

- Всё через **VK Bridge**, без сторонних SDK и mock.
- Rewarded x2: награда только после completed; при ошибке не начислять.
- Ошибка rewarded — тихая надпись под x2:
  «Реклама временно недоступна. Попробуйте позже.»
  Автоскрытие 3–4 с, не чаще 1 раза в 30 с; raw error — только в лог.
- Interstitial: после боя, когда игрок посмотрел итоги и нажал «В лобби»;
  не перед боем, не в матчмейкинге, не в обучении.
- Новичок — не чаще 1/30 мин; не новичок — каждый выход в лобби.
- Interstitial не показался — без сообщения, всегда переходить в лобби.
- VK Голоса/платежи — M4; цены в валюте площадки; серверная проверка.

### 3.6. Один PCK для VK/OK

- Отдельная OK-игра не нужна; OK — тот же PCK с OK-адаптером.
- **Один PCK** для VK/OK (+ standalone fallback), один HTML.
- `Platform` выбирает адаптер в runtime:
  - OK — `vk_client=ok`/URL/`local_access_token`;
  - VK — launch params/sign/VK Bridge;
  - иначе — Standalone.
- VK/OK app URL — тонкие shell/redirect на один build; launch params
  при редиректе сохранять.
- OKi, OK-ссылки, отдельный прогресс — runtime, не отдельный PCK.
- OK-адаптер и код параллельного агента не удалять; вложить в один PCK.
- Три текущих PCK — временно; после стабилизации убрать.

### 3.7. Yandex

- После VK/OK, когда игра готова.
- Не копия и не форк: тот же исходник, `YandexAdapter`, Yandex SDK,
  отдельный билд `web-yandex`.
- В Yandex-сборку не попадают VK Bridge/VK/OK адаптеры и ссылки.
- VK/OK код остаётся в репо для их сборок.

### 3.8. Скины, оружие, магазин

- 2D-карточки скинов (Варвар, Охотница) — идея; текущая правка откачена.
  Не блокер модерации; вернуться позже, без переделки всей сетки.
- Оружие в инвентаре — просто «Надеть/Снять»; в бою показывается модель.
- Легендарное оружие/посох должны светиться (эмиссия/аура), а не быть
  просто одного цвета; клиппинг через шляпу убрать.
- «Купить осколки» — кнопка-заглушка видна; панель пишет
  «Пополнение недоступно», пока нет реальной оплаты.
