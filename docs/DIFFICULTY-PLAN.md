# Кривая сложности и онбординг

## Цель

Закрыть замечание модерации ВК «кривая сложность»: новичок не должен попадать
сразу к ветеранам и не должен тонуть в 3v3 с Оболочкой и осколком.

Опора: правила VK 4.2.4 (понятность, обучение), 4.1.6.4 (недостаточно
проработано), 2.1.3 (не вводить в заблуждение).

## Слой 1. Обязательное обучение

Первый запуск: кнопка «Играть» ведёт в обучение, а не в обычный матч.
Повторно — из лобби; скип в любой момент; факт прохождения/скипа сохраняется.

Сценарий (4–5 минут):

1. Управление и камера.
2. **1 бот** — дуэль: автоатака, уклонение, первая способность.
3. **2 бота** — позиционирование, смена цели, вторая способность.
4. **3 бота** — команда, Оболочка, осколок, доставка.
5. Короткий экзамен 3v3 с ботами; игрок в обучении не умирает.
6. «Обучение пройдено» → лобби.

Уже есть: цель, управление, 3 способности, лавка, Оболочка, осколок,
неуязвимость, AFK-ИИ. Добавить этапы с 1/2/3 ботами и прогресс «1/3».

## Слой 2. Новичковый пул (первые ~10 матчей)

- Матчи 1–3: 1–2 живых новичка + лёгкие боты; боты ходят, бьют, используют
  способности, но слабее и медленнее.
- Матчи 4–7: больше живых, боты нормальные, их меньше.
- Матчи 8–10: почти все живые, 1–2 бота-заполнителя.
- 11+: обычный пул; боты только добивают комнату.

Если живых нет — комната заполняется ботами, игрок не ждёт. Сильных новичков
(KDA/винрейт) выпускать раньше 10 матчей, чтобы не гоняли ботов.

## Уровни ботов

Профили `easy` / `normal` / `hard`:

- `easy`: урон ×0.6, HP ×0.8, агрессия 0.2–0.5, кулдауны ×1.5.
- `normal`: текущие ×0.8 / ×1.15 / ×1.2.
- `hard`: урон ×1.0, HP ×1.1, агрессия 0.6–1.0.

Сервер кладёт `bot_difficulty` в `match_start`; хост применяет к локальным ботам,
сервер — к их HP/урону при валидации. Боты не должны быть «мебелью»: движение,
атака, способности, реакция на Оболочку/осколок.

## Сервер

- Считать матчи игрока (`matches_played` или COUNT по `matches`).
- Флаг `novice` / `novice_until`.
- Матчмейкинг: сначала новичковый пул, потом обычный; боты добивают.
- `match_start`: `bot_difficulty`, число ботов.
- Телеметрия: win rate, смерти, длительность, доля ботов, скип обучения.

## Правила и честность

- Экран «Правила» в лобби и паузе: цель, управление, Оболочка, осколок,
  магазин, победа.
- В правилах/загрузке честно указать: «в первых матчах могут быть боты для
  обучения». Не выдавать ботов за живых с фейковым чатом.
- Никакого pay-to-win: оружие/скины — косметика, боевые предметы — за игровое
  золото в матче.

## Критерии готовности

- Первый «Играть» → обучение; скип работает; повторный запуск не заставляет
  проходить снова.
- В обучении есть 1 → 2 → 3 бота, игрок не умирает, прогресс виден.
- Первые 10 матчей: боты слабее, их количество уменьшается, живые новички
  смешиваются.
- Новичок не встречает ветеранов в первых матчах.
- Есть экран правил и телеметрия.
- Модератор может пройти обучение и понять игру без объяснений.

## Текущее состояние (D1 сделан 24.11.2026)

- Обучение обязательное для нового профиля, скип есть: 1v1 → фонтан/лавка →
  2v2 с союзным ботом → 3v3 без Оболочки → отдельный финал с Оболочкой.
  Игрок не погибает; кулдауны/HP сбрасываются перед боями.
- В 3v3 враги ждут на выходе своей базы и выходят группой; в финале врагов
  нет, Оболочка пассивна и появляется после 3-секундного телеграфа.
- Профили ботов `easy`/`normal`/`hard`; `normal` сохраняет прежние значения
  (×0.8 урон, ×1.15 интервал, ×1.2 кулдауны). Сервер и клиент используют одни
  множители HP/урона.
- Новичковый пул: `players.matches_played`/`novice`, отдельные комнаты для
  новичков, 1–3 матча — easy, 4–7 — normal, 8–10 — normal с малым числом ботов;
  ранний выпуск при 4 победах из 5.
- Экран правил в лобби и паузе; телеметрия `tutorial_*` и `match_start/end` с
  `bot_difficulty`, `novice`, `matches_played`.
- `hard` реализован, но в текущем пуле не выбирается: оставлен для сильных
  новичков/будущего тюнинга.
- Pay-to-win нет; уровни не дают статов.
- Проверки и кадры — `docs/QA-D1.md`.
