# Задачи «Небесные осколки»

Обновлено: 19.11.2026.

## Сделано и задеплоено

- [x] **Матчмейкинг:** боты заполняют комнату через 30 с после последнего игрока, таймер перезапускается на каждом входе. Проверено: входы 0/8/16 с → одна комната.
- [x] **Live-лобби:** сервер присылает `lobby_state` при каждом входе/выходе (состав, команды, `starts_in_ms`). Новый игрок появляется в поиске сразу; таймер серверный, бой стартует ровно на 0. Проверено с `ProbeFriend` и двумя клиентами.
- [x] **Баланс команд сразу:** в поиске один игрок в Свете, второй во Тьме; на старте команды не меняются.
- [x] **HP/alive sync:** сервер раз в секунду присылает авторитетные HP/alive; клиент применяет. Клиентские `stats` не могут понизить HP; боты не лечатся от хоста; смерть от сервера обрабатывается.
- [x] **Модели/капсулы:** герои грузятся по явному пути `character.tscn`; в бою модели, не капсулы.
- [x] **2D-арт:** итоги — keyart; магазин — 2D-лица и 2D-оружие (меч/посох/арбалет); инвентарь 3D.
- [x] **Ник на телефоне:** явный `DisplayServer.virtual_keyboard_show` по тапу/фокусу, скрытие при закрытии. Требует проверки в VK webview.
- [x] **Настройки:** «Авторы и лицензии» и крошечный красный сброс прогресса внизу, ниже «Назад».
- [x] **Обучение:** подсказка «клавиша 1 (Num 1)» для ПК, мигающая кнопка и «НАЖМИ» над ней.
- [x] **Загрузка:** наш сниппет вместо стандартной заставки Godot.
- [x] **Предзагрузка:** VFX, Оболочка и модели героев прогреваются на экране поиска.
- [x] **Джойстик:** невидимый, зона нажатия работает.
- [x] **FPS-панель:** верхний центр, под паузой.
- [x] **Плашки ников:** компактнее, свой ник и враги; имена союзников скрыты.
- [x] **Мобильный профиль:** 3D 0.6, физика 30 Гц, без теней/glow/тумана/SSAO/декоративных OmniLight, частицы вдвое меньше; HUD 10 Гц.
- [x] **VK:** универсальная иконка 576×576 загружена.
- [x] **Веб:** `index_20261118_234006.pck`; старый `223556.pck` оставлен для кэша VK.
