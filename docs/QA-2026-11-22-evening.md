## Фикс 1: HP Оболочки у хоста

Причина: сервер в эхе `shell_state` отправлял `spawn_id=0`; клиент отбрасывает
пакеты со старым id, поэтому хост не применял серверный HP.

- Тест `TestShellStateEchoKeepsSpawnID`: до фикса `got 0 want 4`, после — PASS.
- Сервер: `room.shell.SpawnID = room.shellSpawnID` перед broadcast.
- Клиент: хост больше не берёт `phase/timer` из эха; расписание 2/4/6/8 остаётся
  его, из эха применяются только `alive/hp`.
- Проверка (9-минутный QA-матч): `S hp=723 → 584 → 494 → 324`,
  спавны 120/240/360/480, смерти и циклы чистые, 0 ошибок.

## Фикс 2: решающая Оболочка в sudden death

При равенстве на 10:00 клиент спавнит одну Оболочку сразу; сервер завершает матч
на первой доставке (`handleCrystalDeliver`, ветка sudden death).

- Проверка (QA, sudden death форсирован через 5 с обычного матча):
  `[SHELL-AUDIT] sudden_death_spawn t=600.0` → `spawn` → смерть → осколок →
  доставка → `begin match result`.
